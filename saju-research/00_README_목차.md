## 2. 추천 학습 순서

### A. 가족 사주를 봐주고 싶다 (약 4주 과정)
1. **1주차 — 글자 익히기**: 01번. 10천간·12지지·오행 생극을 외울 때까지 반복합니다.
2. **2주차 — 명식 세우기**: 02번. 내 사주를 만세력 앱 2개로 세우고 손으로 검산합니다. 02번의 완전 예제(1990-05-15 10:30 서울 남성 → 庚午·辛巳·庚辰·辛巳)를 똑같이 따라 해 봅니다.
3. **3주차 — 읽는 법**: 03번 → 04번. 십신을 붙이고 신강·신약과 용신까지 판단합니다.
4. **4주차 — 실전**: 05번의 가상 명조 시연을 따라 읽은 다음, 14번 워크시트로 가족 한 명씩 정리합니다. 06·07번으로 가족 관계를 봅니다.
5. 손금·관상(08·09번)은 사주를 보완하는 대화 소재로 활용합니다.

### B. 사주 사이트를 만들고 싶다
02번(계산 정확도) → 13번(구축) → 11번(법률·윤리) → 12번(경쟁사·마케팅) → 06·07번(인기 콘텐츠인 궁합·재회).

## 3. 반드시 알아야 할 핵심 주의사항 5가지

1. **한국 출생자의 시간 보정** (02번)
   - 1954~1961년에는 한국 표준시가 UTC+8:30이었습니다.
   - 서머타임은 1948~1951, 1955~1960, 1987~1988년에 시행됐습니다.
   - 서울은 표준 경선(동경 135도)보다 약 32분 늦습니다.
   - 이 세 가지를 어떻게 처리하느냐에 따라 **시주, 때로는 일주까지** 달라집니다.
2. **중국산 만세력 라이브러리 함정** (02·13번)
   - lunar-python, lunar-javascript, sxtwl은 절기를 **중국 시간(UTC+8)**으로 계산합니다.
   - 한국 시각을 그대로 넣으면 입춘·절입 경계에서 연주·월주가 틀립니다. 예: 1990-02-04 10:30 출생이 실제로는 己巳년 丁丑월인데 庚午년 戊寅월로 나옵니다.
   - 한·중 음력은 하루씩 어긋나는 날이 있습니다(예: 1997년·2027년 설날).
3. **야자시·조자시** (02번): 밤 11시~자정 출생자는 유파에 따라 일주가 달라집니다. 어떤 기준을 썼는지 항상 기록합니다.
4. **고전 근거와 업계 해석은 다릅니다**: '재회운', 궁합 점수화, 오행별 행운의 색·방위 같은 내용은 고전 근거가 없거나 약한 현대 해석입니다. 각 파일에 구분해 표시했습니다.
5. **상담 윤리** (07·11번): 질병·사망·이혼을 단정해서 말하지 않습니다. 불안을 키워 결제를 유도하지 않습니다. 위기 신호가 보이면 전문기관을 안내합니다.

## 4. 이 자료집의 신뢰도 — 정직한 안내

### 조사 환경의 한계
- 이 자료집은 클라우드 환경에서 조사했습니다. 이 환경은 네트워크 정책 때문에 **위키백과·KCI·RISS·한국천문연구원 같은 사이트의 원문 페이지를 직접 열 수 없었습니다.**
- 사실 확인은 대부분 **웹 검색 결과의 발췌·요약**으로 했습니다. 그 웹 검색도 조사 도중 한도(200회)가 소진됐습니다.
- 직접 열어 대조한 것은 GitHub 원본뿐입니다(IANA 시간대 DB, 만세력 라이브러리 소스, 법령 원문 사본).

### 그래서 이렇게 표시했습니다
| 표시 | 의미 |
|---|---|
| 각주 `[^n]` | 출처가 있음. 파일 끝 "참고 출처"에 URL과 함께 정리 |
| (미확인) | 확인하지 못함. **사이트에 게시하기 전에 반드시 재확인** |
| (통설, 원문 대조 미확인) / (통용 표, 원전 대조 미완) | 현대 해설서들이 공통으로 쓰는 내용이지만 고전 원문과는 대조하지 못함 |
| 업계 통용 해석 | 고전 근거가 아니라 현대 상담 업계에서 쓰는 해석 |

### 비교적 단단한 부분

- 한국 표준시와 서머타임 날짜: IANA tz 원본을 근거로 했습니다.
- 사이트 구축용 라이브러리 정보, 개인정보보호법·전자상거래법 조문
