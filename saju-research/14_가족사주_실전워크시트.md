# 14. 가족 사주 실전 워크시트

> 이 문서는 01~09번 자료를 실제로 **가족 한 사람씩 적용해 보는 작업지**입니다.
> 각 단계 옆의 `→ 0X번` 표시는 근거와 상세 설명이 있는 파일입니다.
> 명리학·궁합·손금·관상은 과학적으로 검증된 예측 체계가 아니라 전통 해석 체계입니다(→ 11번). 가족에게 이야기할 때는 **"경향과 성찰의 도구"**로 전하고, 질병·사망·이혼 같은 단정적인 말은 하지 않습니다.

---

## 0. 준비물

- [ ] 가족 구성원별 **양력 생년월일 + 출생 시각(분 단위) + 출생지**
  - 음력 생일만 알면 음력인지, 윤달인지 꼭 확인 (→ 02번)
  - 출생 시각을 모르면 시주는 비워 두고 **삼주(三柱)**로만 봅니다. 억지로 추정하지 않습니다.
- [ ] 만세력 도구 1개 이상(앱이나 사이트, → 12번), 가능하면 2개로 교차 확인
- [ ] 이 워크시트 사본(가족 1명당 1부)

## 6단계. 가족 관계도 → 06번

가족 전원의 명식을 다 세운 뒤 작성합니다.

| 관계 | A 일간·일지 | B 일간·일지 | 일간 관계(생/극/합) | 일지 관계(합/충/원진) | 서로 용신을 보완하는가 | 메모 |
|---|---|---|---|---|---|---|
| 부-모 | | | | | | |
| 부-자녀1 | | | | | | |
| 모-자녀1 | | | | | | |
| 자녀1-자녀2 | | | | | | |

**해석 원칙**
- 충(沖)이나 원진이 있다고 "안 맞는다"로 끝내지 않습니다. **어떤 상황에서 부딪히기 쉬운지, 어떻게 보완하면 좋은지**로 풀어 줍니다.
- 부모-자녀 궁합은 **양육 방식 조언**(이 아이는 칭찬형인지 자율형인지 등)으로 쓰면 가장 쓸모가 있습니다.

## 실수 방지 체크리스트

- [ ] 만세력 2개로 교차 확인했는가
- [ ] 중국산 만세력(절기를 UTC+8로 계산)을 썼다면, 입춘·절입 근처 출생자의 연주·월주를 한국 시각 기준으로 다시 확인했는가 (→ 02번)
- [ ] 서머타임·표준시·경도 보정 중 **무엇을 적용했는지 기록**했는가
- [ ] 절입일 근처 출생자의 월주·연주를 다시 확인했는가
- [ ] 출생 시각이 불확실하면 시주 해석을 보류했는가
- [ ] 흉한 내용을 단정적으로 말하지 않았는가(→ 11번 윤리)
- [ ] 건강 관련 내용은 "검진 권유" 수준으로만 말했는가
