# 05. 대운(大運)·세운(歲運) 작동 원리와 실전 해석

> **이 문서의 위치**: `03`(십신·궁위·신강약·합충·신살)과 `04`(격국·용신·조후)로 **원국의 구조**를 읽은 뒤, 이 문서에서는 **시간(운)** 을 얹어 실제로 해석하는 방법을 정리합니다. 대운수 계산과 만세력 작성은 `02`를 따릅니다.
>
> **전제**: 명리학은 과학적으로 검증된 예측 체계가 아니라 **전통 해석 체계**입니다. 서양 점성술을 대상으로 한 이중맹검 실험에서도 예측력을 지지하는 결과는 나오지 않았고[^31], 사주명리를 대상으로 한 대규모 통제 검증 연구는 이번 조사에서 확인하지 못했습니다(미확인). 운 해석은 **경향과 주의점을 성찰하는 도구**로 쓰고, 사건을 단정적으로 예언하는 데 쓰지 않습니다(4장 참조).
>
> **조사 방법 메모**: 웹 검색 결과 요약으로 확인했고, 네트워크 정책 때문에 원문 페이지를 직접 열지는 못했습니다. 원전 대조를 마치지 못한 내용에는 **(미확인)** 또는 **(통용 견해)** 를 붙였습니다.

## 1. 운(運)의 구조와 작동 원리

### 1.1 세 겹의 시간

| 단위 | 이름 | 길이 | 교체 기준(통용) | 비유 |
|---|---|---|---|---|
| **대운(大運)** | 10년 운 | 10년 | 대운수 나이에 교체(02 참조) | 계절, 지형, 날씨의 큰 흐름 |
| **세운(歲運)·유년(流年)·태세(太歲)** | 1년 운 | 1년 | **입춘(立春)** | 그해의 날씨 |
| **월운(月運)** | 1달 운 | 약 30일 | **절기(節)**: 입춘·경칩·청명… | 그달의 기온 |
| (일운·日運) | 하루 | 1일 | 자시(子時) 기준(야자시·조자시 학파차) | 실무 비중 낮음 |

- **원국은 "사람(그릇)"이고, 대운은 그 사람이 걷는 "길"이며, 세운은 그 길 위의 "그해 날씨"** 라는 비유가 통용됩니다(통용 비유).
- 세운이 입춘에 바뀐다는 것은 자평명리의 통설입니다. 다만 음력 설이나 동지(冬至)를 기준으로 삼는 소수 견해도 있다고 알려져 있습니다(미확인). 사이트에서는 **입춘 기준**을 기본값으로 쓰고 이를 명시하기를 권합니다.

### 1.2 대운의 생성 (요약)

| 항목 | 규칙(통용) |
|---|---|
| 방향 | **양남음녀(陽男陰女) 순행**, **음남양녀(陰男陽女) 역행**. 연간의 음양과 성별로 정함 |
| 출발 | **월주(月柱)** 다음(순행) 또는 이전(역행) 간지부터 60갑자 순서로 진행 |
| 대운수 | 출생 시각부터 다음 절입(순행) 또는 이전 절입(역행)까지의 날수 ÷ 3 = 대운 시작 나이(3일 = 1년) |
| 길이 | 각 대운 10년 |

- 이 규칙은 실무서 전반의 통설입니다. 이번 조사에서 원전(『연해자평』·『삼명통회』) 구절로는 대조하지 못했습니다(원전 대조 미완). 남자는 순행하고 여자는 역행한다는 "고서의 규칙"을 오랜 검증 끝에 옳다고 판단했다는 현대 저자의 주장도 있지만[^46], 통설과 다른 소수 견해입니다.
- 대운수 계산의 세부(나머지 날수 처리, 시간 단위 환산, 만 나이/세는 나이)는 `02`의 기준을 따르세요.

### 1.3 대운 간지의 해석 방식: 학파 차이

| 견해 | 내용 | 메모 |
|---|---|---|
| **천간 5년·지지 5년 분할** | 대운 10년 가운데 앞 5년은 천간, 뒤 5년은 지지가 주관 | 대운 10년의 길흉을 간지가 각각 5년씩 맡는다는 서술이 확인됨[^32] |
| **10년 통합** | 간지를 한 덩어리로 보아 10년 내내 함께 작용 | 현대 실무에서 많이 쓰임(통용 견해) |
| **지지 중시** | 대운 지지가 **계절(월령의 연장)** 이므로 지지 비중이 더 큼 | 『적천수』 계열 실무자에게 많은 견해(통용 견해, 원전 미확인) |

> 권장 실무: **10년 통합으로 보되 지지(계절·환경)를 더 무겁게, 천간(드러난 사건·태도)을 함께** 읽고, 분할설은 참고로 표시합니다.

### 1.4 운의 작동 원리 다섯 가지

1. **운은 원국을 통해서만 작동한다**: 운의 글자는 원국 글자와 생극·합충할 때 의미가 생깁니다. 원국에 없는 오행이 운에서 오면 "새로운 요소의 등장"으로 읽습니다.
2. **용희기(用喜忌)가 길흉 방향을 정한다**: 용신·희신 운은 대체로 순조롭고, 기신·구신 운은 저항이 큽니다(`04` 3.6).
3. **십신이 사건의 영역을 정한다**: 재성 운이면 재물·(남명) 이성, 관성 운이면 직장·(여명) 남편처럼 읽습니다(3장).
4. **궁위가 사람과 장소를 정한다**: 운이 일지를 충하면 배우자궁, 시지를 충하면 자녀궁처럼 읽습니다(`03` 5장).
5. **대운이 세운보다 우선하지만, 사건은 세운에서 터진다**: 대운은 "배경 조건", 세운은 "촉발 시점"으로 봅니다(통용 견해).

### 1.5 교운기(交運期)

- 대운이 바뀌는 앞뒤 1~2년은 환경 변화가 많은 시기로 봅니다(통용 견해, 원전 미확인).
- 특히 **용신 대운에서 기신 대운으로 넘어갈 때** 주의를 당부하고, 반대로 넘어갈 때는 회복을 해석합니다.

## 2. 원국과 운의 합충 관계 읽는 법

### 2.1 천간: 운의 천간이 원국 천간과 만날 때

| 관계 | 해석 원칙 | 예 |
|---|---|---|
| 운간이 원국 천간과 **합** | 해당 원국 글자가 묶임(합반) → 그 십신의 작용이 약해지거나 성격이 바뀜 | 세운 丙이 원국 월간 辛(정관)과 합 → 직장·남편성 관련 "묶임·계약·이동"의 상징 |
| 운간이 원국 천간을 **극** | 그 십신이 손상 | 운의 상관(丁)이 원국 정관(辛)을 극 → 상관견관: 직장·명예·(여명)남편 관계에서 마찰 경계 |
| 운간이 일간을 **극** | 일간에 압력 | 칠살 운: 신강이면 성취, 신약이면 스트레스 |
| 운간이 일간과 **합** | 내가 그 글자를 취함 | 남명 甲 일간에 己 정재 운 = 재물·배우자 인연의 상징 |

### 2.2 지지: 운의 지지가 원국 지지와 만날 때

| 관계 | 해석 원칙 | 체크 포인트 |
|---|---|---|
| **충(沖)** | 해당 궁위·십신의 변동 | 어느 궁위인가? 충받는 글자가 용신인가 기신인가? |
| **육합·반합·삼합** | 결속, 세력 형성 | 합으로 형성된 오행이 용신 쪽인가? 합으로 용신이 묶이는가? |
| **형(刑)** | 마찰·조정·법적 절차 상징 | 단정 금지, 보조 판단 |
| **원국 충을 운이 합으로 해소** | 긴장 완화 | 탐합망충 |
| **원국 합을 운이 충으로 깨뜨림** | 묶여 있던 것이 풀림(해방 또는 이별) | 궁위 확인 |
| **공망 글자가 운에서 옴** | 공망 해소(전실·塡實)라는 견해 | `03` 8.12 |

### 2.3 대운과 세운의 상호작용

| 상황 | 해석 경향(통용 견해) |
|---|---|
| 대운·세운 모두 용희신 | 가장 순조로운 해 |
| 대운 용신·세운 기신 | 큰 흐름은 좋으나 그해 일시적 장애 |
| 대운 기신·세운 용신 | 어려운 시기 속 숨통이 트이는 해 |
| 대운·세운 모두 기신 | 무리하지 말고 방어적으로 운영할 해 |
| **세운이 대운을 충(歲運沖大運)** | 환경의 급변, 큰 결정이 몰리는 해로 봄 |
| 대운·세운·원국이 **삼합·방합 완성** | 해당 오행이 폭발적으로 강해짐 → 용신 쪽이면 큰 기회, 기신 쪽이면 큰 부담 |
| 같은 글자가 원국·대운·세운에 겹침(복음·伏吟) | 같은 일이 반복되거나 정체됨 |
| 운이 원국 기둥을 천충지충(天沖地沖, 반음·反吟) | 해당 궁위의 큰 변동 |

### 2.4 운 판독 체크표 (해마다 반복)

```text
[대운]
[ ] 대운 천간 십신 / 용희기
[ ] 대운 지지 십신 / 용희기 / 계절
[ ] 대운 지지 ↔ 원국 지지: 합·충·형 (어느 궁위?)
[ ] 대운 천간 ↔ 원국 천간: 합·극

[세운]
[ ] 세운 천간 십신 / 용희기 → 원국·대운 천간과의 합·극
[ ] 세운 지지 십신 / 용희기 → 원국·대운 지지와의 합·충·형
[ ] 세운이 대운을 충하는가?
[ ] 원국+대운+세운으로 삼합·방합이 완성되는가?

[결론 정리]
[ ] 영역(십신) × 사람·장소(궁위) × 방향(용희기) 세 축으로 요약
[ ] 단정 대신 "경향·주의·기회" 언어로 문장화 (4.3)
```

## 3. 영역별 해석 가이드

> 각 영역은 **(1) 보는 별(십신), (2) 보는 자리(궁위), (3) 운의 신호, (4) 체크리스트** 순서로 정리합니다. 키워드는 통용 해석이며, 개별 출처를 원전과 대조하지는 못했습니다(통용 해석).

### 3.1 성격

| 요소 | 읽는 법 |
|---|---|
| 일간 | 기본 기질 (甲=곧고 성장 지향, 乙=유연·적응, 丙=밝고 외향, 丁=섬세·집중, 戊=듬직·포용, 己=실속·세심, 庚=결단·의리, 辛=예리·완벽, 壬=지략·포부, 癸=감수성·지혜) |
| 월령과 격 | 사회적 성격의 틀(정관격=원칙형, 식상격=표현형, 재격=현실형, 인수격=학구형, 칠살격=돌파형) |
| 십신 분포 | 가장 많은 십신과 아예 없는 십신 (`03` 3.2) |
| 강약 | 신강=주도적, 신약=협조적·민감 (단순화 주의) |
| 신살 (보조) | 도화=매력, 화개=내향·예술, 역마=활동, 귀문=예민 |

- **체크**: 일간 + 격 + 최다 십신 + 결핍 십신 + 강약을 조합해 3~5문장으로 요약합니다. 부정적 특성은 "에너지가 과할 때 나타날 수 있는 모습"으로 표현합니다.

### 3.2 적성·직업

| 구조 | 적성 경향(현대 해석) |
|---|---|
| 관인상생(官印相生) | 공공기관, 교육, 연구, 대기업 관리, 자격 기반 전문직 |
| 식신생재(食神生財) | 기술 기반 사업, 요식, 제조, 콘텐츠 사업 |
| 상관생재(傷官生財) | 기획, 마케팅, 프리랜서, 예술 사업, 스타트업 |
| 상관패인(傷官佩印) | 학문적 표현, 저술, 강의, 법률·언론 |
| 식신제살·살인상생 | 의료, 군경, 위기관리, 법조, 조직 리더 |
| 재생관(財生官) | 경영관리, 금융, 행정 |
| 비겁 강 + 식상 | 독립 전문직, 개인 사업 |
| 종격 | 따르는 오행의 직업군(종재=사업·금융, 종살=조직·권력, 종아=예술·기술) |

- **운의 신호**: 관성 운에 승진·입사·자격, 식상 운에 창업·이직·창작, 재성 운에 사업 확장·수입 변화, 인성 운에 학업·자격·문서 같은 상징을 읽습니다.
- **체크**: (1) 격과 상신 → (2) 용신의 십신 → (3) 용신 오행의 직업 상징(`04` 6.2, 근거 약함) → (4) 현실 조건(학력·경험·흥미) 순서로 보고, (4)를 반드시 우선합니다.

### 3.3 재물

| 보는 것 | 요점 |
|---|---|
| 재성의 유무·강약 | 재성이 뿌리가 있고 쓸 만한가 ("財氣通門戶")[^4][^43] |
| 신강약 | 재를 감당할 힘(신강)이 있는가. 신약재다면 재물이 오히려 부담 |
| 재의 근원 | 식상이 재를 생하는가(생산형 재물) |
| 재의 분탈 | 비겁이 재를 빼앗는가(동업·보증 주의) |
| 재의 보호 | 관성이 비겁을 막아 재를 지키는가 |
| 재고(財庫) | 재성의 묘고(辰戌丑未) 존재, 개고(충) 여부 (통용 견해) |

- **운의 신호**: 재성 운 + 신강 → 수입 기회. 재성 운 + 신약 → 일이 많고 지출도 큼. 비겁 운 → 지출·경쟁. 식상 운 → 재물을 만드는 활동 증가.
- **주의**: 투자 시기·종목 추천은 하지 않습니다(4.3).

### 3.4 건강 (전통 오행-장부 대응)

> ⚠️ 아래 대응은 동아시아 전통 의학의 오행 배속을 명리에 응용한 **상징 체계**입니다. 질병을 진단하거나 예측하지 않으며, 증상이 있으면 반드시 의료기관을 이용하도록 안내합니다. 대응의 원전(『황제내경』 「음양응상대론」 등) 구절은 이번 조사에서 원문 대조하지 못했습니다(원문 대조 미완).

| 오행 | 장(臟) | 부(腑) | 관련 조직·감각(전통) | 감정(전통) |
|---|---|---|---|---|
| 木 | 간(肝) | 담(膽) | 근(筋), 눈 | 노(怒) |
| 火 | 심(心) | 소장(小腸) | 혈맥, 혀 | 희(喜) |
| 土 | 비(脾) | 위(胃) | 기육(肌肉), 입 | 사(思) |
| 金 | 폐(肺) | 대장(大腸) | 피모(皮毛), 코 | 비(悲)·우(憂) |
| 水 | 신(腎) | 방광(膀胱) | 골(骨), 귀 | 공(恐) |

- **읽는 법(전통)**: (1) 극을 심하게 받는 오행, (2) 지나치게 많은 오행, (3) 충을 받는 지지의 오행을 "관리 포인트"로 봅니다. 예) 金이 왕하고 木 일간이 약하면 간담·근육계 피로를 "관리 포인트"로 표현합니다.
- **사이트 표현 예**: "전통 오행 상징으로는 木이 약해 간·근육 쪽 관리 습관을 권하는 해석이 있습니다. 건강 판단은 의료 전문가에게 받으세요."

### 4.2 해석의 우선순위 원칙

1. **원국 > 대운 > 세운 > 월운**: 원국에 없는 큰 사건을 운만으로 만들어 내지 않습니다.

3. **월령 > 일지 > 시지 > 연지**: 일반적인 영향력 순서입니다(통용 견해).
4. **인접 > 격위(隔位)**: 붙어 있는 합충이 먼 합충보다 강합니다.
5. **불확실하면 복수 시나리오**: "A일 가능성, B일 가능성"으로 제시하고 내담자의 실제 경험으로 좁혀 갑니다.

### 5.3 3단계: 격국

- 월지 酉의 본기 **辛(정관)이 월간에 투출** → **정관격(正官格)**. 투출 순서상 다툼이 없는 깔끔한 사례입니다(`04` 2.2 STEP 2).
- 성격 조건 점검 (`04` 2.4)
  - 관인상생: 연간 癸(정인), 일지 子(정인)가 정관을 받아 일간을 생함 → **충족**
  - 상관견관: 원국에 상관 없음 → **파격 요소 없음**
  - 관살혼잡: 편관 庚은 酉의 지장간에만 있음 → **혼잡 경미**
  - 재생관: 재성 없음 → 미충족(약점)
- **판정**: 『자평진전』 기준 **정관격 관인상생(官印相生) 성격**. 상신(相神)은 인성입니다.

### 5.4 4단계: 강약과 용신

**강약**

| 기준 | 판정 |
|---|---|
| 득령 | ✘ (酉월, 金 왕절 = 관성) |
| 득지 | ✔ (일지 子 정인, 시지 寅 건록 = 강한 뿌리) |
| 득세 | ✔ (癸·亥·子 인성 3, 寅 비견) |
| 예시 점수 (`03` 6.4 가중치) | 아군 = 子15 + 寅12 + 亥10 + 癸8 = 45 / 타군 = 酉30 + 辛10 + 丙10 = 50 → **약 47%** |
| 결론 | **중화(中和)** 범위, 인성이 많아 체감상 약간 신강 쪽 |

**용신 후보 비교**

| 관점 | 분석 | 후보 |
|---|---|---|
| 격국(자평진전) | 정관격 관인상생 성격. 상신 = 인성. 인성을 깨뜨리는 재성(土)이 오면 파격 위험 | 상신 **인성(水)** 보호 |
| 억부 | 중화~약간 신강. 인성 과다 쪽으로 기움 → 설기(식상)나 재성(인성 제어)이 필요 | **火(식상)**, 土(재성) |
| 조후(궁통보감) | 酉월 甲木 → 庚·丁·丙 (요약표 기준, 미확인 칸)[^11]. 가을에 水가 3개라 한습(寒濕) 경향 → 따뜻하게 할 火가 필요. **丙이 시간에 투출하고 寅에 뿌리** | **丙火** |
| 병약 | 병 = 인성(水) 과다 → 수다목부(水多木浮)의 염려. 약 = 土(재성)로 수를 제어. 원국에 土 없음 → 운에서 기다림 | **土** (운에서) |

**최종 판단과 근거**

- **용신: 丙火(식신)**: 조후와 억부(설기)가 일치하고 원국에 투출·통근해 있어 "쓸 수 있는 용신"입니다.
- **희신: 木** (용신을 생함, 견해 A·B 공통).
- **기신: 水** (용신 火를 극하고 이미 과다). 다만 정관격의 상신이 인성이므로, 원국의 水는 **"적당히 있어야 할 것이 이미 충분히 있는 상태"** 입니다. 운에서 水가 더 오면 부담이 된다는 뜻입니다.
- **구신: 金** (기신 水를 생함). 단, 정관 자체는 격의 주체이므로 金 운은 "직위·명예 기회 + 인성 과다 가속"의 양면으로 읽습니다.
- **한신: 土** (자동 배정상 한신). 다만 **병약 관점에서는 길한 작용**(인성 과다 제어, 재성 보충)이 있어 **실질적으로는 희신에 가깝게** 봅니다.

> 이처럼 실전에서는 자동 배정(`04` 3.6)과 구조 판단이 어긋나는 경우가 많습니다. 사이트에서 자동 판정을 보여 줄 때는 "자동 배정 결과"와 "구조 보정 의견"을 나눠 표시하는 설계를 권합니다.

### 5.5 5단계: 원국 정적 해석

| 영역 | 해석 (전통 해석 체계 기준) |
|---|---|
| **성격** | 甲木 일간에 정관격 관인상생 → 원칙과 책임을 중시하고 배움을 좋아하는 성향. 인성이 많아 신중하고 생각이 깊지만, 결정을 미루거나 생각이 많아질 수 있음. 시간 丙 식신은 따뜻한 표현력과 가르치는 재능으로 읽음. 子酉 귀문이 인접해 감수성이 예민하다는 해석 |
| **적성·직업** | 관인상생 → 공공·교육·연구·자격 기반 조직과 잘 맞는 구조. 용신 丙(식신) → 강의, 교육, 상담, 콘텐츠처럼 "배운 것을 표현하는" 직무에서 힘을 낸다는 해석 |
| **재물** | 재성이 원국에 드러나 있지 않음 → 사업형 재물보다 전문성·직위를 통한 수입(급여·전문 수수료)이 맞는 구조로 해석. 土 운에 재물 관리·자산 형성 기회 |
| **건강 (상징)** | 金이 왕한 계절의 木 일간, 水 과다 → 전통 대응으로는 간담·근육(木), 신장·냉증(水)을 관리 포인트로 언급. 용신 火 → 체온·순환 관리 습관. **의료 판단 아님** |
| **학업** | 인성이 강하고 관인상생이라 학업·자격시험에 유리한 구조로 읽음. 단, 인성 과다는 "공부량에 비해 실행이 늦다"로 나타날 수 있음 |
| **결혼 (여명)** | 남편성 정관(辛)이 월간에 투출하고 월지에도 있음, 관살혼잡이 약함 → 전통적으로 "남편성이 맑다"고 봄. 배우자궁(일지) 子는 정인 → 배우자와의 관계가 돌봄과 지지의 성격을 띤다는 상징. 일지 子와 월지 酉가 파·귀문 관계 → 관계 안에서 예민함을 다루는 대화가 중요 |
| **자녀 (여명)** | 자녀성 식신 丙이 **자녀궁(시주)** 에 있고, 그 丙이 **용신** → 자녀와의 인연과 자녀로 인한 기쁨을 상징하는 전통적 해석. 시지 寅은 역마(일지 子 기준) → 자녀가 활동적이거나 멀리 나가는 상징 |
| **부모** | 정인(어머니) 癸가 연간에 투출하고 일지 子에도 있음 → 어머니의 영향이 큰 성장 환경의 상징. 편재(아버지) 土는 원국에 드러나지 않음 → 아버지 별이 약하게 나타남(단정 금지. 실제 관계는 내담자에게 확인) |

### 5.6 6단계: 신살 보조

| 신살 | 해당 여부 | 해석 (보조) |
|---|---|---|
| 천을귀인 (甲: 丑·未) | 원국 없음 → 운에서 丑·未가 올 때 귀인 작용 | 乙丑 대운, 未년 |
| 역마 (일지 子 → 寅) | **시지 寅** ✔ | 활동성, 말년·자녀궁의 이동성 |
| 도화 (일지 子 → 酉 / 연지 亥 → 子) | **월지 酉, 일지 子** ✔ | 대인 매력. 도화가 정관(酉)이라 "공적 자리에서의 호감·신뢰"로 현대적 재해석 |
| 공망 (甲子순 → 戌·亥) | **연지 亥** ✔ | 연주(조상·초년)의 편인이 공망 → 초년 환경이나 조부모 덕이 약하다는 전통적 해석. 癸亥 대운에서 전실(塡實) |
| 귀문 (子–酉) | **월지–일지 인접** ✔ | 섬세한 감수성·직관. 정신건강 진단으로 쓰지 않음 |
| 원진 (寅–酉) | 시지–월지(떨어져 있음) | 약함, 참고만 |
| 양인·백호·괴강·홍염 | 해당 없음 | — |

### 5.8 8단계: 정리와 전달 (상담 문장 예시)
