# 19. 건강운 — 전통 해석을 출처별로 쪼개 세고, 겹치는 해석 찾기

> 작성일: 2026-10-28
>
> **전제**: 명리학·구성기학(九星気学)은 과학적으로 검증된 진단·예측 체계가 아닙니다. 이 파일은 **"전통 해석 체계 안에서는 건강을 이렇게 본다"** 는 정보를 한국·일본·중국어권(중국 본토·대만·홍콩) 출처에서 모아, **출처별로 쪼개 기록하고 같은 해석이 몇 곳에서 독립적으로 나오는지 센** 자료입니다. 여러 곳이 같은 말을 하면 "전통 안의 합의"라고 부를 수 있을 뿐, 의학적으로 맞다는 뜻은 아닙니다. 건강 해석을 가족이나 사이트에 쓸 때는 반드시 9장(윤리)을 먼저 읽으세요.
>

### 0.1 확인 수준 표시

| 표시 | 뜻 |

| **원문 확인** | 이번 조사에서 그 페이지·문서·PDF를 직접 열어 읽음 (WebFetch 또는 PDF 텍스트 추출) |

### 0.2 겹침 판정 규칙

- **현대 출처만** 나라별로 셉니다(한=한국, 일=일본, 중=중국어권). 고전은 "고전 근거" 칸에 따로 적고 나라 수에 넣지 않습니다.
- **합의 높음**: 서로 다른 출처 3곳 이상 + 2개 나라(권역) 이상.
- **단일권역 다수**: 3곳 이상이지만 한 나라에서만 나옴.
- **소수 의견**: 1~2곳.
- **충돌**: 출처끼리 반대로 말함. 양쪽을 모두 적습니다.
- 같은 저자·같은 카페의 여러 글은 1곳으로 셉니다(예: 프레시안 김태규 칼럼 2편 → K2 1곳).

### 0.3 조사 환경과 한계 (정직한 안내)

- ctext.org는 자동 접근을 막아 열지 못했습니다. 대신 **維基文庫(zh.wikisource)** 에서 『황제내경』·『주역』·『적천수』·『삼명통회』·『연해자평』·『궁통보감』 원문을 직접 열었습니다. 위키문헌 판본은 교감본이 아니라서 오자가 있을 수 있습니다(2.3절 참조).
- 知乎(zhihu)·명천기(mingtianji) 등 일부 중국 사이트, 일본 ml-con.com·allabout.co.jp는 403으로 막혀 검색 발췌만 봤습니다. PubMed는 로봇 확인 화면이 떠서 **Europe PMC 공식 API**로 초록을 확인했습니다.
- 조사 도중 **웹 검색 한도(세션 공용 200회)가 소진**됐습니다. 그 뒤로는 이미 찾은 주소만 열었습니다. 그래서 한국 쪽 현대 해설서·KCI 논문은 기대보다 적게 모였습니다(11장).
- 한국 법령(law.go.kr)은 자바스크립트 화면이라 조문 원문을 읽지 못했습니다. 9장의 법률 내용은 **(미확인)** 입니다.

### 1.3 대표 충돌

1. **甲=간인가 담인가**: 『삼명통회』 「甲膽乙肝」 vs 위키문헌 『연해자평』 「甲肝乙膽」 (3.3절).
2. **눈병은 火가 넘쳐서인가, 火가 꺼져서인가**: 『궁통보감』은 火가 뜨겁고 水가 없을 때 目疾, 『삼명통회』 계열과 盲派는 火가 水에 극당할 때 눈병 (6장 H24).
3. **지지 신체 대응표가 두 계통**: 『삼명통회』 「子屬膀胱水道耳…」 vs 『연해자평』 「子疝氣 丑肚腹…」 (3.4절).
4. **九星의 심장**: 九紫火星이라는 곳, 六白金星이라는 곳, 五黄土星이라는 곳이 나뉨 (4.3절).
5. **부족한 오행 = 약한 장부인가**: 대부분 "그렇다", 일부는 "부족한 오행이 기신이면 오히려 좋다" (H32).
6. **사주로 병을 예측할 수 있나**: 한국 논문·칼럼 일부는 "충분히 예측 가능", 일본·한국 사이트 다수는 "경향일 뿐 진단 아님" (H37).

## 2. 고전 근거

### 2.1 『황제내경(黃帝內經)』 소문 — 오행-장부 배속의 뿌리 [C1][C2] (원문 확인)

명리의 건강 해석은 거의 모두 이 배속표를 빌려 씁니다. 「음양응상대론(陰陽應象大論)」 제5편의 오방(五方) 구절입니다[C1].

| 방위 | 在藏為 (장) | 在體為 (몸) | 在竅為 (구멍) | 在志為 (감정) | 감정이 상하게 하는 장 |
|---|---|---|---|---|---|
| 東方 (木) | 肝 | 筋 | 目 | 怒 | 怒傷肝 |
| 南方 (火) | 心 | 脈 | 舌 | 喜 | 喜傷心 |
| 中央 (土) | 脾 | 肉 | 口 | 思 | 思傷脾 |
| 西方 (金) | 肺 | 皮毛 | 鼻 | 憂 | 憂傷肺 |
| 北方 (水) | 腎 | 骨 | 耳 | 恐 | 恐傷腎 |

「금궤진언론(金匱眞言論)」 제4편에는 계절풍과 병의 자리가 나옵니다[C2].

- 「東風生於春，病在肝，俞在頸項」 — 봄바람은 간에 병, 목덜미에 혈(俞).
- 「南風生於夏，病在心，俞在胸脇」 / 「西風生於秋，病在肺，俞在肩背」 / 「北風生於冬，病在腎，俞在腰股」 / 「中央為土，病在脾，俞在脊」.
- 같은 편의 오색 구절: 「東方青色，入通於肝，開竅於目」, 「南方赤色，入通於心，**開竅於耳**」, 「北方黑色，入通於腎，**開竅於二陰**」.

> **고전 안의 차이**: 「음양응상대론」은 心의 구멍을 **舌**, 腎의 구멍을 **耳**라고 하는데, 「금궤진언론」은 心을 **耳**, 腎을 **二陰**(대소변 구멍)이라고 합니다. 현대 명리 사이트는 거의 전부 앞의 것(心=舌, 腎=耳)을 씁니다.

### 2.2 『주역(周易)』 「설괘전(說卦傳)」 — 九星気学 신체 대응의 뿌리 [C3] (원문 확인)

- 제9장: 「乾為首，坤為腹，震為足，巽為股，坎為耳，離為目，艮為手，兌為口。」
- 제11장, 坎에 대해: 「其於人也，為加憂、為心病、為耳痛、為血卦、為赤。」

일본 九星気学 사이트들이 一白水星(坎)에 귀·혈액·심장병을 붙이는 것은 이 구절에서 온 것으로 보입니다(4.3절). 다만 사이트들은 이 출처를 밝히지 않습니다.

### 2.3 『적천수(滴天髓)』 「疾病論」 [C4] (원문 확인, 위키문헌 『滴天髓輯要』 1.35)

본문(굵게)과 원주(原注)를 짧게 인용합니다.

| 원문 | 풀이 |
|---|---|
| **「五行和者，一世無災。」** | 오행이 조화로우면 평생 재앙이 없다. |
| 「五行和者，不特全不缺，生而不剋…全者宜全，缺者宜缺…則和矣」 | "조화"란 다섯 개가 다 있다는 뜻이 아니다. 있어야 할 것은 있고, 없어야 할 것은 없는 상태다. |
| **「血氣亂者，平生多疾。」** | 혈기가 어지러우면 평생 병이 많다. |
| 「五氣反逆，上下不通，往來不順，皆為亂」 | 기가 거꾸로 돌고 위아래가 통하지 않는 것이 "어지러움"이다. |
| **「忌神入五臟而病凶。」** | 기신(忌神)이 오장에 들면 병이 흉하다. |
| 「忌木而入土者脾病，忌火而入金則肺病，忌土而入水則腎病，忌金而入木則肝病，忌水而入火則心病」 | 꺼리는 木이 土 자리에 들면 비장병 … (오장 = **장**) |
| 「又看虛實，如木入土，土旺者，則脾有餘之病…土衰者，則…不足之病」 | 같은 극이라도 土가 왕하면 실증(有餘), 쇠하면 허증(不足). |
| **「客神遊六經而災小。」** | 객신(客神)이 육경(六經)을 떠돌면 재앙이 작다. |
| 「木遊於土地而胃病，火遊金地而大腸病，土行水地而膀胱病，金行木地而膽病，水行火地而小腸病」 | 같은 구조라도 부(腑)에 걸리면 가볍다. |
| **「木不受水者血病。」** | 木이 충을 받거나 허탈해 水를 받지 못하면 혈병. 「蓋肝屬木而藏血」 |
| **「土不受火者氣傷。」** | 土가 火를 받지 못하면 기가 상함. (원주에 「蓋膽屬土而容火」라고 돼 있는데, 膽은 木이므로 **판본 오자**로 보임. 확인 필요) |
| 「金水傷官，寒則冷嗽，熱則痰火；火土印綬，熱則風痰，燥則皮癢」 | **조후와 체질의 고전 근거.** 금수상관이 차면 냉해수, 뜨거우면 담화. 화토인수가 뜨거우면 풍담, 건조하면 피부 가려움. |
| 「論痰多木火，生毒鬱火金，金水枯傷而腎經虛，水土相勝而脾胃洩」 | 담은 木火, 독창(毒)은 火金, 金水가 마르면 신경(腎經) 허, 水土가 다투면 비위 설사. |
| 「…如土為妻，土受傷應剋妻，而不剋者，或其人恆患脾病，則亦足以當之矣」 | 육친 흉이 맞지 않으면 본인이 그 오행의 병을 앓아 "대신 응한다"고 봄. |

**요점**: 『적천수』는 (1) 균형(和), (2) 기의 흐름(亂), (3) **기신(忌神)이 어느 장부 자리에 드는가**, (4) 장(臟)은 무겁고 부(腑)는 가볍다, (5) 한난조습(寒暖燥濕)을 기준으로 삼습니다. 현대 해설서의 "부족한 오행 = 약한 장기" 같은 단순 공식은 『적천수』의 핵심이 아닙니다. 『적천수』는 **용신·기신 판단을 먼저** 합니다.

### 2.4 『삼명통회(三命通會)』 권7 「論疾病先知五臟六腑所屬干支」 [C5] (원문 확인)

- 첫머리 가결(장부): 「甲膽乙肝丙小腸，丁心戊胃己脾鄉；庚是大腸辛屬肺，壬係膀胱癸腎藏；**三焦亦向壬中寄，包絡同歸入癸鄉**。」
- 천간 외형: 「又曰：甲頭**乙頂**丙肩求，丁心戊肋己屬腹；庚是臍輪辛屬股，壬脛癸足一身由。」
- 지지: 「子屬膀胱水道耳，丑為胞肚及脾鄉；寅膽發脈並兩手，卯本十指內肝方；辰土為皮肩胸類，巳面咽齒下賓肛；午火精神司眼目，未土胃脘隔脊梁；申金大腸經絡肺，酉中精血小腸藏；戌土命門腿踝足，亥水為頭及腎囊。」
- 총론: 「夫疾病皆因五行不和，即人身五臟不和也。」 「是以五行太過不及，皆主疾也。」(『내경』을 끌어와 "東方實者，木太過也；西方虛者，金不及也…")
- 극(剋): 「甲乙見庚辛申酉多者，內主肝膽驚悸、勞瘵、手足頑麻、筋骨疼痛」, 「木逢金克，定主腰肋之災」.
- 사절(死絕): 「金死絕，主氣虛喘急、咳嗽、皮毛焦燥…大腸泄痢、便血之疾」, 「土死絕，主面黃、減食…喜卧嗜睡、多思…」, 「木死絕虛風目澀眩暈…」.
- 상극 쌍: 「金木相克，生旺主肢足骨節不完、眼目之疾」, 「水土相克，主脾濕泄瀉、中滿痰嗽不利之疾」.
- 火 과다: 「遇丙丁火多無水相濟，則痰喘咯血、中風不語、皮膚乾燥，內熱口乾」.
- 형충: 「日時衰敗，大患難療；干支刑害，小疾不療。」 「凡命見真沖氣散，或真刑氣散，多是廢疾之人。」
- 성별: 「丙火上炎，丈夫每忌於身心；丁火下濕，女人虛癆而血產。」
- 같은 권에 「論小兒」 절이 따로 있습니다(「夫觀小兒之命，如種花木之法」).

### 2.5 『연해자평(淵海子平)』 「論疾病」 [C6] (원문 확인, 위키문헌 『淵海子平大全』 8절)

- 장부: 「**甲肝，乙膽**，丙小腸，丁心，戊胃，己脾鄉，庚是大腸，辛屬肺，壬是膀胱，癸腎臟。」 → 『삼명통회』와 甲·乙이 **반대**.
- 천간 외형: 「甲頭，**乙項**，丙肩求，丁心，戊脅，己屬腹，庚係人臍，辛為股，壬脛，癸足自來求。」 → 乙이 『삼명통회』는 頂(정수리), 여기는 項(목덜미).
- 지지: 「子疝氣，丑肚腹，寅臂肢，卯目手，辰背胸，巳面齒，午心腹，未脾胸，申咳疾，酉肝肺，戌背肺，亥頭肝。」 → 『삼명통회』 지지 가결과 **다른 계통**.
- 총칙: 「八字干支，五行生剋之義，取傷重者而斷之；五行干支太旺、不及俱病。」
- 오행별: 「木命見庚辛申酉多者，肝膽病。」 「火命見水及亥子旺地，主小腸、心經之患。」 「土命見木及寅卯旺鄉，主脾、胃經受傷。」 「金命見火及巳午旺處，主大腸、肺經受病。」 「水命見土及四季旺月，主膀胱、腎經受病。」
- 장부 기능: 「腎通於眼，膽藏魂，肝藏魄…」 (현행 중의학의 "肝藏魂·肺藏魄"과 다름. 판본 문제일 수 있음)

### 2.6 『궁통보감(窮通寶鑑)』 속 질병 언급 [C7] (원문 확인, 위키문헌 전문)

『궁통보감』은 조후(계절) 중심의 책이라 질병을 따로 다루지 않지만, 일간·월별 항목에 질병어가 흩어져 있습니다. 이번에 찾은 것만 적습니다.

| 일간·월 | 원문 | 구조 |
|---|---|---|
| 甲木 정·2월 | 「或支成火局，洩露太過，定主愚懦，常有啾唧災病纏身，終有暗疾」 | 木이 火에 지나치게 설기 |
| 甲木 정·2월 | 「或支成金局，多透庚辛…號曰木被金傷，若無丙丁破金，必主殘疾」 | 木이 金에 상함 |
| 甲木 8월 | 「支成金局，干露庚金，為木被金傷，必主殘疾，得丙丁破金，亦主老來暗疾」 | 金 과다. **늙어서 숨은 병** — 나이 언급 |
| 甲木 5·6월 | 「若柱中多金，名曰殺重身輕…非貧即夭」 | 칠살 과다 |
| 乙木 5월 | 「若見丙透，支成火局，陽焦木性，此人殘疾，無癸必夭，見壬可解」 | 조열 |
| 丙火 정월 | 「用癸無根，定主目疾」 | 水 약 → 눈병 |
| 丙火 5월 | 「支火輕，無目疾」 (같은 항목에 「瞽目之人」) | 火 과다 → 눈병 |
| 戊土 5월 | 「…且主目疾」 | 여름 土 조열 |
| 己土 여름 | 「但恐目疾，心腎肝臟之災」 | 여름 土 조열 |
| 癸水 4월 | 「又無比肩羊刃，必至熬干癸水，損目無疑」 | 火가 癸水를 말림 → 눈 |
| 癸水 정월 | 「或火多土多，殘疾不免」 | 水가 약하고 火土 과다 |
| 癸水 12월 | 「或支成木局，洩水太過，主殘病呻吟」 | 설기 과다 |
| 壬水 4월 | 「若見一甲藏寅，與巳相刑，主有暗疾」 | **刑**과 숨은 병 |

**『궁통보감』의 패턴**: 눈병(目疾)은 주로 **여름·火가 강하고 水가 말랐을 때** 나옵니다. "잔질(殘疾)"은 주로 **일간이 극·설을 과하게 받을 때** 나옵니다. "夭(요절)"이라는 말이 질병보다 훨씬 자주 나옵니다. 이런 표현은 현대 상담에 그대로 쓰면 안 됩니다(9장).

## 4. 일본 — 四柱推命 健康運과 九星気学

### 4.1 일본 四柱推命 健康運의 경향 (J1~J5)

1. **오행 균형 → 臓器 대응**이 기본: 거의 모든 사이트(J1·J2·J3·J4)가 『내경』식 오행-장부표로 시작합니다.
2. **大過와 不及을 나눔**: 교본 소개 블로그 J2는 "不及은 그 오행의 장기, 大過는 극하는 쪽 장기"라고 정리합니다.
3. **통변성(通変星)으로 보는 계통**: 新栄堂 J1은 偏印(倒食)·傷官·羊刃·劫殺·12운(病死墓絶)을 중심에 둡니다. 「健康体の基本条件」으로 身旺, 病気の星がないこと, 五行のバランス, 十二運の安定, 食神の健旺을 꼽습니다.
4. **주의 문구가 강함**: J3 「四柱推命でわかるのは『傾向』であって、『診断』ではありません」, J4 「医学的な診断や治療に代わるものではありません」. 한국·중국어권 사이트보다 면책 문구가 더 자주, 더 분명하게 들어갑니다.
5. **漢方·약선과 결합**: 宮幹藍后 『改訂版「眞医」陰陽五行四柱推命学』(オークラ出版) 소개문 「『漢方』と『四柱推命学』で病気を予防しましょう」, 「まずはあなたの臓器の弱点を探し、どんな食事をとった方がよいのかを把握する」 [J5]. 책 본문은 확인하지 못했습니다.
6. **일간(日干)별 체질 팁**: J3은 甲乙=간·신경, 丙丁=심장·혈압, 戊己=위장, 庚辛=호흡기·피부(건조 대책), 壬癸=신장·냉증(몸을 데우기)으로 정리합니다.

### 4.2 九星気学의 体調·病気 보는 법

- 九星気学은 본명성(本命星)마다 「象意(しょうい)」 목록이 있고, 그 안에 "人体"·"病気" 항목이 들어갑니다. 그 뿌리는 『주역』 「설괘전」의 팔괘 신체 대응입니다[C3].

## 5. 중국어권 — 八字看疾病

### 5.1 "八字看疾病" 절차 (출처가 공통으로 말하는 순서)

3. **장부·부위 대응표 적용** — 천간·지지 가결과 궁위 [Z5][Z6].
4. **형충·상극 확인** — 다친 글자가 몸의 어느 부분을 맡는지 [Z4][Z5].
5. **대운·유년이 그 약점을 건드리는 때** [Z1][Z4][Z9].

대만 문서 Z1은 중의의 팔강(陰陽·表裏·寒熱·虛實)을 명리에 옮깁니다: 表裏=천간·지지, 寒熱=오행 조습(燥濕), 虛實=왕쇠("過則為實，不及為虛").

### 5.2 盲派

- 段建业 강의록(Z4): 「看疾病與八字做功沒關係」(검색 발췌 문구, 163.com). 즉 **부귀를 보는 "做功"과 건강 판단은 별개**이고, 궁위·간지의 상(象), 음양 평형, "부서진 글자가 몸의 어디인가"를 본다는 입장입니다. 음양은 「陰陽要相交相融，不可夬離」, 특히 양을 잃는 것을 위험하게 봅니다. 차(車)의 상으로 辰·丑·酉·申·子와 역마를 쓰고, 화(火)의 충·해를 속도로 봅니다.

**7.3절에서 말할 수 있는 것**
- 출생 계절과 일부 질환(다발성경화증, 조현병, 일부 심혈관·알레르기)의 위험 사이에 **작지만 재현되는 관련**이 있습니다. 효과는 몇 %~수십 % 수준의 **상대 위험 차이**이고, 개인에게 "당신은 무슨 병에 걸린다"고 말할 수 있는 크기가 아닙니다.
- 남반구에서 패턴이 뒤집히는 것(S5)은 **계절 환경**이 원인이라는 증거이고, 달력상의 간지(干支)가 원인이라는 해석과 맞지 않습니다. 같은 甲子年 생이라도 남반구에서 태어나면 계절이 반대입니다.

**말할 수 없는 것**
- 출생 계절 연구는 **월(계절) 단위**입니다. 사주처럼 일주·시주까지 나눈 정밀한 예측을 뒷받침하지 않습니다.
- 한국인 대상으로 같은 크기의 출생월-질환 연구는 이번에 확인하지 못했습니다.

### 7.4 사상체질 연구와의 관계

- 한국한의학연구원의 사상체질 연구 동향 논문(이영섭·김상혁·이시우, 『한국한의학연구원논문집』 18(1), 2012, 원문 확인)은 2007~2010년 논문 142편을 분석했습니다. 체질 진단은 체형·성질·용모·병증(이제마 기준)과 맥진기·설문·유전자(FTO, MC4R)로 연구되며, **출생 연월일로 체질을 정하는 연구는 이 동향에 나오지 않습니다.**
- 류시옥[K1]은 "사상체질은 체질 구별 기준이 부족하니 사주가 더 객관적"이라고 주장하지만, 그 근거 자료는 제시하지 않습니다.

## 9. 윤리 — 건강 해석을 가족·사이트에 쓸 때

### 9.1 원칙

1. **질병 단정 금지**: "○○병에 걸린다", "몇 살에 수술한다", "암 체질"처럼 병명·시점을 단정하지 않습니다. 고전의 「必主殘疾」, 「非貧即夭」, 盲派의 「必做無頭鬼」 같은 표현은 **인용할 때도 현대 상담 문장으로 바꿔 쓰지 않습니다.**
2. **의료 대체 금지**: 사주 해석은 진찰·검사·치료를 대신하지 못합니다. 증상이 있으면 의료기관을 먼저 안내합니다.
3. **치료 지연을 부르는 말 금지**: "올해는 수술 운이 나쁘니 미뤄라", "귀월에는 수술하지 마라" 같은 말은 실제 해를 끼칠 수 있습니다. 대만 의사들도 귀월 공포로 수술을 미루는 것이 더 위험하다고 경고한 보도가 있습니다(S12, 검색 발췌).
4. **정신건강 진단 금지**: 귀문관살·편인 과다·인성 대과 = 정신질환 같은 연결은 낙인입니다(`03`·`05`와 같은 방침).
5. **공포 판매 금지**: 건강 불안을 이용해 부적·굿·개명·건강식품을 파는 연결을 만들지 않습니다(`11` 3-6절).
6. **아이·노인 사주에 더 조심**: 『삼명통회』 「論小兒」나 盲派의 "소아 肝風" 같은 규칙을 부모에게 전하면 불필요한 불안을 만듭니다.

### 9.2 한국 법률 주의 (전부 **미확인** — 게시 전에 법령 원문과 전문가 확인 필요)

- **의료법상 의료행위**: 의료법은 의료인이 아닌 사람의 의료행위를 금지하는 것으로 알려져 있습니다(제27조로 알려짐, **이번에 조문 원문 확인 못함**). 사주 상담이 "진단"이나 "처방"처럼 보이면 문제가 될 수 있습니다. 특히 다음은 피합니다.
  - 특정 질병이 "있다/없다"고 판정하는 말
  - 약·한약·건강기능식품의 복용·중단을 권하는 말
  - 검사·치료·수술을 받지 말라거나 미루라는 말
- **의료광고**: 의료인이 아닌 사람이 질병 예방·치료 효과를 광고하는 것도 제한되는 것으로 알려져 있습니다(의료법 제56조 등, **미확인**). 사이트 문구에 "사주로 질병 예방", "건강 진단" 같은 말을 쓰지 않습니다.
- **표시·광고**: "적중률", "의학적으로 입증" 같은 표현은 `11`번 3-4절의 표시광고 주의와 같습니다.
- **일본**: 일본 의사법(医師法)도 의사가 아닌 사람의 의업(医業)을 금지하는 것으로 알려져 있습니다(**미확인**). 일본 사이트들이 "診断ではありません"을 반복하는 배경으로 보입니다.
